## Quiénes somos

Somos un equipo de ingenieros de software peruanos especializado en **arquitectura de sistemas escalables**. No entregamos solo aplicaciones: diseñamos plataformas pensadas para crecer, con código revisado, pruebas automatizadas y despliegue continuo desde el primer commit.

Trabajamos con las tecnologías que están definiendo el mercado actual y aplicamos metodologías ágiles (Scrum, BDD) para que tu producto llegue antes y mejor.

<td width="50%" valign="top">

## Cómo trabajamos

```text
   Consultoría  ──▶  Arquitectura  ──▶  Desarrollo  ──▶  CI/CD  ──▶  Soporte
   (gratuita)        contrato API      sprints + BDD    lint·test·build
```

- **Contrato primero.** La API se documenta con OpenAPI antes de escribir la pantalla que la consume.
- **Calidad automatizada.** Ruff y oxlint en cada push; cobertura de pruebas como condición de merge.
- **Observabilidad desde el día uno.** Sentry y logs estructurados en todos los servicios en producción.
- **Documentación viva.** Cada proyecto mantiene su estado implementado versionado junto al código.
