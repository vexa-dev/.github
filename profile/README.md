## Quiénes somos

Equipo de ingenieros peruanos especializado en **arquitectura de software escalable**. Diseñamos plataformas web, aplicaciones móviles y sistemas de gestión pensados para crecer: código revisado, pruebas automatizadas y despliegue continuo desde el primer commit.

| | Servicio | |
|:--|:--|:--|
| **01** | **Consultoría en transformación digital** | Definimos qué software necesita tu negocio — `gratuita` |
| **02** | **Desarrollo web** | Landing pages, portafolios y sitios corporativos |
| **03** | **Aplicaciones móviles** | Apps nativas e híbridas para iOS y Android |
| **04** | **Gestión de inventario** | Control de stock y transacciones en tiempo real |
| **05** | **Gestión de personal** | Asistencias, planillas y métricas corporativas |
